## Design Context

### Register
Product. This is a working image generation and editing tool; design serves repeated prompt writing, parameter tuning, reference-image workflows, and history reuse.

### Users
Creators, developers, designers, and technically comfortable users who run image generation through OpenAI-compatible, fal.ai, or custom providers. They use the app to iterate quickly, compare outputs, reuse prior settings, and keep data local.

### Product Purpose
Provide a fast local-first workspace for generating and editing images, managing API profiles, reference images, masks, generation parameters, and history. Success means users can move from idea to prompt to result with minimal friction and clear control over parameters.

### Brand Personality
Practical, precise, and polished. The interface should feel like a calm production tool rather than a marketing page or a decorative gallery.

### Aesthetic Direction
Product UI with restrained editorial craft: dense but readable layouts, clean structure, tinted neutrals, controlled contrast, and selective green/ink accents for the prompt template library. Avoid generic neon-dark AI aesthetics.

### Anti-References
Avoid marketing landing pages, oversized hero sections, purple-blue gradients, glassmorphism-heavy panels, decorative card nesting, anime/game-first prompt library presentation, and playful toy-like controls.

### Design Principles
1. Keep creation controls close to the workflow.
2. Prefer scannable density over decorative spaciousness.
3. Make every action reversible or explicit when it overwrites user input.
4. Use visual hierarchy to separate generation, history, settings, and template discovery.
5. Preserve the local-first, production-tool feel.

### Accessibility & Inclusion
Support light and dark mode, keyboard closing for modal surfaces, readable text at mobile widths, clear focusable controls, reduced visual noise, and no critical functionality hidden on mobile.
